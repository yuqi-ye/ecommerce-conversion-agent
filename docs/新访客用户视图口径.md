# 新访客用户视图口径（第一版）

用户 MySQL 时间差截图：完全一致 256766 人、负差 3 人、正差不超过1秒 120 人、超过1秒至1天 279 人、超过1天 146 人，共 257314 人。

主分析采用最早 first_visit 与 first-touch 完全相等的用户，排除购买先于首访的人。这是可复现的保守分析定义，不是对548个差异用户判定为无效。所有用户保留在视图，原始表不删记录。后续以放宽时间一致性要求的人群做敏感性比较，评估指标变化后再形成结论。两名购买先于首访者属于时间不一致组，因此不会额外减少完全一致组。

用户视图每人一行。首次获客来源和设备取最早首访记录。首访最早时刻已检查为唯一。purchased_7d 使用 [t0,t0+168小时)，以最早购买判断是否购买；购买先于首访的异常用户标记 NULL，观察期不足也标记 NULL，不能当未购买。

原始表后缀连续覆盖2020-11-01至2021-01-31，全部事件的 event_date 与 UTC 日期一致。第一版依据这些证据，约定样本覆盖到2021-02-01 00:00 UTC（不含），并非由最大事件时间外推。无法独立核实公开样本上游采集是否完备，这是分析限制。

比较完整的周一至周日首访周，并要求该周全部时刻都有完整7日窗口：纳入首访 UTC 时间 [2020-11-02 00:00,2021-01-25 00:00)，即周起始2020-11-02至2021-01-18，共12周。2020-11-01是不完整周，1月25日及以后不满足整周后续观察要求。
